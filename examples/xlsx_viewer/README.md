# Excel 结构对齐工具

独立的 PySide6 + openpyxl 本地桌面示例，代码仅位于 `examples/xlsx_viewer`，
不修改 XlsxWriter 核心。中文界面提供查看、结构分析、逐项复核、另存及验证。

## 安装与启动

Python 3.10 或更新版本，在仓库根目录执行：

```sh
python3 -m venv .venv-viewer
source .venv-viewer/bin/activate
python -m pip install -r examples/xlsx_viewer/requirements.txt
python examples/xlsx_viewer/viewer.py
```

Windows 使用 `py -m venv .venv-viewer` 和 `.venv-viewer\Scripts\activate`。
桌面运行需要 Qt 系统图形库；Linux 的离屏测试也可能需要 libEGL/libGL。

## 工作流程

1. 打开 `.xlsx` / `.xlsm`，用工作表下拉框查看单元格。表格不可编辑，公式显示文本。
   搜索框对当前工作表做不区分大小写的包含匹配；回车或“下一个”向后跳转，
   “上一个”反向跳转并循环，`Ctrl+F` 聚焦搜索框。
2. 点击“分析结构”。工具在前 20 行、前 10 列查找唯一的“项目名称”表头，
   提取后续非空标签。至少 3 个标签、所有成员间顺序相似度达到 0.9 才自动归组
   （两表均不超过 10 个标签的短模板使用 0.8）；
   其他表独立列出。重复标签用前面的唯一标签作为上下文，仍不唯一时阻断。
3. 选择组，在工作表列表勾选至少两张候选表，点击“重新生成计划”。
   操作和阻断仅基于该子集。术语候选提供标签对和原因，可勾选“视为同一项目”后重新生成；
   改变工作表子集时清除旧术语确认，再展示该子集的候选。
   点击操作会切换到源表并选中对应行。操作复选框决定应用哪些插入。
   新行号按完整选择计算；仅选择部分操作时，会重新计算实际位置，但不保证完成整组对齐。
4. 点击“另存对齐副本”，选择 `data/` 之外、扩展名相同且不存在的新文件名。
   保存禁用时，查看阻断原因或选中有效操作。“结构一致”的组不需要保存。
   **一次保存只应用当前组的所选子集**；其他组需打开副本后继续，此限制也显示在界面中。
5. 保存完成后查看“已保存并验证”及下方报告；再用 Excel 打开副本复核公式计算和对象外观。

当前策略是确定性的精确顺序并集：保留每一原始行，在缺项处插入带标签、邻近样式的空白
模板行，不复制业务数值或推算公式，不删除原始行。未标记的行及备注列也整体下移。
不统一绝对行号、空白行或表头高度。顺序冲突不自动重排；同一空隙中不能确定顺序的标签
（包括可能的同义词）显示阻断，不默认认定为同一项目。显式等价仅改变匹配，
不改写任一原标签或常量；插入缺项使用候选对第一项的规范显示标签。
等价确认不解决顺序循环，也不会自动重排行。

## 保存与验证保证

- 分析只读；源文件永不覆盖。仓库 `data/` 下所有路径禁止作为输出。也拒绝源文件的
  符号链接/硬链接别名及已有目标文件。不执行宏、公式或外部链接。
- 保存重新加载源文件，按持久化的工作表子集及术语确认重新分析并检查 SHA256。
  候选对、组成员及操作均重新验证，客户端行坐标不作为可信输入。
- 通过 openpyxl 保留单元格值/类型、样式、数字格式、批注、超链接及行高/隐藏状态。
  合并区域随行移动；插入位置穿过合并区域时阻断。新行只复制样式和标签。
- 普通公式通过 Tokenizer 分析，A1 单元格及矩形区域按实际插入行调整，包括跨表和绝对引用。
  这是插行语义，不是复制公式的相对位移语义。外部引用和整列引用在公式自身不移动时原样保留；
  同一公式中的本地 A1 引用仍会调整。无行边界变化的整行引用、三维 A1 引用原样保留；
  三维引用跨越的所有表均检查行边界，实际受影响时阻断。
- 无关表的数据验证、条件格式、筛选等不再阻断，并随副本保存。收到插入行的表若含这些功能，
  仍保守阻断；定义名称、数组/数据表公式和无法确认目标的动态地址等仍有限制。
  移动行中的外部/整列等不支持公式仍可阻断。预览执行与保存相同的公式/功能预检。
  已证实无关的字面量 INDIRECT 可保留；受影响或无法判定的动态引用阻断。
- `.xlsm` 以 `keep_vba=True` 加载，外部链接以 `keep_links=True` 保留。
  **openpyxl 不保证不支持的 Excel 对象完美往返，绘图、外部链接等可能变化；不是字节级保真。**
  图表、绘图锚点、分页及其他对象不属于逐格验证范围，必须在 Excel 中复核。
- 保存到目标目录的临时文件，重新打开并验证工作表集合、全部原始非空常量的 Python 值/
  类型及唯一逻辑目标、全部标签、预期公式文本与位置，也检查不存在额外非空单元格。
  验证通过后才原子替换至新目标路径。失败或取消时删除本次暂存文件，不发布目标。
  GUI 在工作进程结束后发布，取消不会让工作进程自行发布副本。强制终止整个应用/系统崩溃
  可能遗留 `.alignment-*` 临时文件。报告显示在界面内，无额外 JSON 文件。
- 验证检查的是逻辑内容和公式文本，**不计算公式、不验证 Excel 计算结果**。

## 响应性及加载限制

分析不加载外部链接缓存（不修改输入）；保存使用 `keep_links=True`。
查看、分析、保存都在独立子进程中执行。加载超时 30 秒，分析超时 120 秒，保存超时 10 分钟（含外部缓存加载及重新打开验证）；
可取消任务，关闭窗口也会终止进程。普通查看不受对齐功能的公式限制影响。
原有上限保留：文件 20 MiB、ZIP 解压声明总量 100 MiB/2000 个条目、100 张单元格表、
每表 10000 行/256 列、显示文本合计 1000000 字符。实际区域会重新扫描，防止不实区域元数据。
子进程不是恶意文件安全沙箱，没有操作系统级内存配额。

查看器不复现 Excel 格式化渲染、合并外观或图表；隐藏表也会列出，图表工作表不显示。
加密文件、旧 `.xls` 和损坏文件会报错。真实 VBA、平台原生对话框及复杂 Excel 对象仍需手测。

```sh
QT_QPA_PLATFORM=offscreen python -m unittest discover -s examples/xlsx_viewer -p 'test_*.py' -v
printf '%s' '{"mode":"analyze","source":"data/HMT/集团财报预测V1.xlsx"}' | python examples/xlsx_viewer/alignment.py
```

测试生成临时工作簿，覆盖查看器原有行为、聚类/并集、重复标签上下文、歧义阻断、常量/
公式/跨表引用、行属性/合并/批注/链接、SHA256、另存拒绝及 GUI 分析复核保存/取消。
